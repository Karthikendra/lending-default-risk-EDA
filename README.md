# Lending Default Risk – Exploratory Data Analysis

## 📌 Project Overview

This project focuses on Exploratory Data Analysis (EDA) of lending default risk data using Python.

The objective is to understand the dataset, assess data quality, identify patterns, analyze borrower characteristics, and explore variables associated with loan default.

---

## 🎯 Objectives

- Understand the structure and characteristics of the dataset.
- Identify missing values and duplicate records.
- Detect suspicious and potentially invalid values.
- Perform univariate and bivariate analysis.
- Analyze relationships between financial variables.
- Explore patterns associated with loan default.
- Generate insights for future credit risk modeling.

---
