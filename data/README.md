# Dataset

This folder contains the dataset used for the Lending Default Risk Exploratory Data Analysis project.

The dataset is used to analyze borrower characteristics, financial variables, data quality, and patterns associated with loan default.

## Dataset File

Lending_Default_Risk_Data.csv :-
- https://github.com/Karthikendra/lending-default-risk-EDA/raw/refs/heads/main/Lending_Default_Risk_Data.csv

## Analysis

The dataset is analyzed for:

- Missing values
- Duplicate records
- Invalid and suspicious values
- Numerical and categorical distributions
- Relationships between financial variables
- Loan default patterns
